RAG application 2026 Live

ChatMyVideo

Paste a YouTube link and ask questions about it. The app pulls the timestamped transcript, embeds it, retrieves the most relevant passages, and answers with an LLM, citing timestamps so you can jump straight to the moment.

  • Semantic retrieval over transcript chunks (E5 embeddings + FAISS)
  • Groq-hosted LLM answers in the video's language
  • FastAPI backend, Next.js frontend
  • Python
  • LangChain
  • FAISS
  • FastAPI
  • LLMs
